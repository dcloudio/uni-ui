# 项目介绍
本项目，uni-ui-x，是DCloud官方为 uni-app x 提供的扩展组件库。包含一系列组件。

uni-ui-x是全新设计的，与为uni-app做的uni ui不同。

# 设计原则
- 性能
uni-ui-x非常注重性能，在DOM层级控制、包体积、代码执行时间方面精益求精。

- 类headless
uni-ui-x专注于逻辑，没有个性化样式，代码精简。
但可以通过css自己控制所有样式。
开发者可通过自定义css类或使用css预处理工具，来自定义自己的特殊风格。
如果没有强调的个性化风格，也可以直接使用uni-ui-x默认风格。

- 优秀的样式抽象
传统的组件把样式封装在组件属性上，造成用户需要自定义样式时无限封装属性，并且这些属性的控制无法使用css变量。
如果不能满足自定义需求，就要查看组件内部的类名进行强制覆盖，甚至修改组件源码。

uni-ui-x的所有样式，都不封装在组件属性上，属性只控制逻辑功能。
父级样式直接透传到组件内部根节点。
对于组件子元素的样式控制，uni-ui-x采用了 web component 的part设计思路，子组件开放partname出来，外部可通过part-class和part-style进行样式自定义。

如果组件内部有些子元素不允许自定义样式（这在uni-ui-x中没有），组件作者不开放子元素的part即可。
如果子元素有些样式不能被覆盖（比如position），组件作者会把这类样式写在内联style的末尾，以控制这类样式的高优先。
