# movable-view 移动容器组件

移动容器组件，可以拖动、缩放组件。

本uni_modules插件包括2个组件，movable-view 和 movable-area。

## 平台支持

本组件仅支持 Web 和 App 平台（uni-app x），不支持微信小程序（微信小程序有内置的 movable-view 组件）。

## 功能特性

- 拖动
- 缩放
